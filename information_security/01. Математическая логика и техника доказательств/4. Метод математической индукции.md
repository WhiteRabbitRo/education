# Лекция 4. Метод математической индукции

## Назначение метода математической индукции

Метод математической индукции применяется для доказательства утверждений, зависящих от натурального параметра: $$P(n), n \in \N.$$

Например, $$1 + 2 + ... + n = \frac{n(n+1)}{2}.$$

Такое утверждение содержит бесконечное множество случаев: $$P(1), P(2), P(3),...$$

Проверить все случаи непосредственно невозможно. Метод математической индукции позволяет доказать сразу все утверждения $P(n)$, начиная с некоторого значения $n_0$.

## Индуктивная схема

> **Определение 4.1. Индуктивное доказательство**
> Чтобы доказать утверждение $$\forall n \ge n_0 : P(n),$$ методом математической индукции необходимо выполнить два шага:
> 1. доказать базовый случай: $$P(n_0);$$
> 2. доказать индукционный переход: $$\forall k \ge n_0 : (P(k) \Rightarrow P(k + 1)).$$
> После этого делается вывод: $$\forall n \ge n_0 : P(n).$$

Схематически: $$P(n_0) \quad \land \quad \forall k \ge n_0: (P(k) \Rightarrow P(k + 1)) \Rightarrow \forall n \ge n_0 : P(n).$$

## Принцип математической индукции

> **Теорема 4.1. Принцип математической индукции**
> Пусть $P(n)$ - утверждение, определенное для всех $n \in \N, \quad n \ge n_0$.
> Если выполнены условия: $$P(n_0),$$ и $$\forall k \ge n_0: (P(k) \Rightarrow P(k + 1)),$$ то $$\forall n \ge n_0 : P(n).$$

_Доказательство:_

Предположим, что утверждение $P(n_0)$ истинно.

Из истинности $P(n_0)$ по индукционному переходу следует истинность: $$P(n_0 + 1).$$

Затем из истинности $P(n_0 + 1)$ следует: $$P(n_0 + 2).$$

Продолжая этот процесс, получаем: $$P(n_0), P(n_0 + 1), P(n_0 + 2), ...$$

Следовательно, $P(n)$ истинно для каждого $n \ge n_0$.

$\square$

## Базовый случай

> **Определение 4.2**
> **Базовым случаем** называется проверка утверждения при первом значении параметра: $$P(n_0).$$

Например, если утверждение доказывается для всех $n \ge 1$, то базовым случаем является: $$P(1).$$

Базовый случай нельзя пропускать.

Индукционный переход может быть формально верным, но без начального истинного значения он не запускает цепочку доказательства.

Аналогия:
* базовый случай - первая костяшка домино;
* индукционный переход - доказательство того, что каждая костяшка сбивает следующую.

Без первой упавшей костяшки остальные могут вообще не упасть.

## Индукционное предположение

> **Определение 4.3**
> На этапе индукционное перехода предполагается, что утверждение верно для некоторого произвольного $k \ge n_0$: $$P(k).$$
> Это предположение называется **индукционным предположением** или **индукционной гипотезой**.
> Затем на его основе доказывается: $$P(k + 1).$$

Индукционное предположение не является утверждением, которое нужно доказать отдельно в рамках перехода. Это временное предположение, используемое для вывода следующего случая.

## Пример: сумма первых натуральных чисел

> **Теорема 4.2**
> Для каждого $n \in \N$ верно: $$1 + 2 + ... + n = \frac{n(n+1)}{2}.$$

_Доказательство:_

Обозначим утверждение: $$P(n): 1 + 2 + ... + n = \frac{n(n + 1)}{2}.$$

Шаг 1. Базовый случай

При $n = 1$ левая часть равна: $$1.$$

Правая часть равна: $$\frac{1(1 + 1)}{2} = \frac{2}{2} = 1.$$

Следовательно: $$P(1)$$ истинно.

Шаг 2. Индукционное предположение

Пусть для некоторого $k \in \N$ верно: $$1 + 2 + ... + k = \frac{k(k+1)}{2}.$$

Это индукционное предположение.

Шаг 3. Индукционный переход

Рассмотрим сумму для $k + 1$: $$1 + 2 + ... + k + (k + 1).$$

Используя индукционное предположение, получаем: 
$$\begin{aligned}
1 + 2 + ... + k + (k + 1)
&= \frac{k(k + 1)}{2} + (k + 1)\\
&= \frac{k(k + 1)}{2} + \frac{2(k + 1)}{2}\\
&= \frac{k(k + 1) + 2(k + 1)}{2}\\
&= \frac{(k + 1)(k + 2)}{2}.
\end{aligned}$$

Но: $$\frac{(k + 1)(k + 2)}{2}$$ имеет форму правой части исходной формулы при $n = k + 1$: $$\frac{(k + 1)((k + 1) + 1)}{2}.$$

Следовательно: $$P(k) \Rightarrow P(k + 1).$$

Базовый случай и индукционный переход доказаны. Поэтому: $$\boxed{\forall n \in \N: 1 + 2 + ... + n = \frac{n(n+1)}{2}}.$$

$\square$

## Пример: сумма квадратов

> **Теорема 4.3**
> Для каждого $n \in \N$ верно: $$1^2 + 2^2 + ... + n^2 = \frac{n(n+1)(2n+1)}{6}.$$

_Доказательство:_

Обозначим: $$P(n): 1^2 + 2^2 + ... + n^2 = \frac{n(n+1)(2n+1)}{6}.$$

__Базовый случай__

При $n = 1$: $$1^2 = 1.$$

Правая часть равна: $$\frac{1 \cdot 2 \cdot 3}{6} = 1.$$

Следовательно, $P(1)$ истинно.

__Индукционное предположение__

Пусть для некоторого $k \in \N$: $$1^2 + 2^2 + ... + k^2 = \frac{k(k+1)(2k+1)}{6}.$$

__Индукционный переход__

Рассмотрим сумму до $k + 1$: $$1^2 + 2^2 + ... + k^2 + (k + 1)^2.$$

По индукционному предположению:
$$\begin{aligned}
1^2 + ... + k^2 + (k + 1)^2
&= \frac{k(k + 1)(2k + 1)}{6} + (k + 1)^2\\
&= \frac{k(k + 1)(2k + 1) + 6(k + 1)^2}{6}.
\end{aligned}$$

Вынесем $(k + 1)$: 
$$\begin{aligned}
&= \frac{(k + 1)(k(2k + 1) + 6(k + 1))}{6} \\
&= \frac{(k + 1)(2k^2 + k + 6k + 6)}{6} \\
&= \frac{(k + 1)(2k^2 + 7k + 6)}{6}.
\end{aligned}$$

Разложим квадратный трехчлен: $$2k^2 + 7k + 6 = (2k + 3)(k + 2).$$

Следовательно: $$1^2 + ... + (k + 1)^2 = \frac{(k + 1)(k + 2)(2k + 3)}{6}.$$

Это именно формула для $n = k + 1$: $$\frac{(k + 1)((k + 1) + 1)(2(k + 1) + 1)}{6}.$$

Следовательно: $$P(k) \Rightarrow P(k + 1).$$

Таким образом: $$\boxed{\forall n \in \N : 1^2 + 2^2 + ... + n^2 = \frac{n(n+1)(2n+1)}{6}}.$$

$\square$

## Пример: делимость

> **Теорема 4.4**
> Для каждого $n \in \N$ число $$7^n - 1$$ делится на 6: $$\forall n \in \N : \quad 6 \mid (7^n - 1).$$

_Доказательство:_

Обозначим: $$P(n): \quad 6 \mid (7^n - 1).$$

__Базовый случай__

При $n = 1$: $$7^1 - 1 = 6.$$

Очевидно: $$6 \mid 6.$$

Следовательно, $P(1)$ истинно.

__Индукционное предположение__

Пусть для некоторого $k \in \N$: $$6 \mid (7^k - 1).$$

Тогда существует $m \in \Z$, такое что: $$7^k - 1 = 6m.$$

__Индукционный переход__

Рассмотрим: $$7^{k + 1} - 1.$$

Преобразуем: $$7^{k + 1} - 1 = 7 \cdot 7^k - 1 = 7(7^k - 1) + 6.$$

Используя индукционное предположение: $$7^k - 1 = 6m,$$ получаем: $$7^{k + 1} = 7 \cdot 6m +6 = 6(7m + 1).$$

Следовательно: $$6 \mid (7^{k + 1} - 1).$$

Значит: $$P(k) \Rightarrow P(k + 1).$$

По принципе математической индукции: $$\boxed{\forall n \in \N : \quad 6 \mid (7^n - 1)}$$

$\square$

## Начало индукции с произвольного числа

Индукция может начинаться не только с 1.

**Пример**

Докажем, что для каждого $n \ge 5$: $$n^2 \gt n + 10.$$

Обозначим: $$P(n): n^2 \gt n + 10.$$

__Базовый случай__

При $n = 5$: $$5^2 = 25,$$ а $$5 + 10 = 15.$$

Следовательно: $$25 \gt 15,$$ то есть $P(5)$ истинно.

__Индукционный переход__

Пусть для некоторого $k \ge 5$ выполнено: $$k^2 \gt k + 10.$$

Тогда: $$(k + 1)^2 = k^2 + 2k + 1.$$

Из индукционного предположения: $$k^2 \gt k + 10.$$

Поэтому: $$(k + 1)^2 = k^2 + 2k + 1 \gt (k + 10) + 2k + 1 = 3k + 11.$$

Так как $k \ge 5$, то: $$3k + 11 \gt k + 11 \gt k + 1 + 10.$$

Следовательно: $$(k + 1)^2 \gt (k + 1) + 10.$$

Значит, $P(k) \Rightarrow P(k + 1).$

Итак: $$\boxed{\forall n \ge 5: \quad n^2 \gt n + 10.}$$

$\square$

## Сильная математическая индукция

Обычная индукция использует только предыдущее утверждение: $$P(k) \Rightarrow P(k + 1).$$

Иногда для доказательства $P(k + 1)$ необходимо использовать несколько предыдущих случаев: $$P(1), P(2), ..., P(k).$$

> **Определение 4.4**
> Для доказательства утверждения $$\forall n \ge n_0 : P(n)$$ методом сильной индукции необходимо доказать:
> 1. базовый случай: $$P(n_0);$$
> 2. сильное индукционное предположение: $$P(n_0) \land P(n_0 + 1) \land ... \land P(k);$$
> 3. переход: $$P(n_0) \land ... \land P(k) \Rightarrow P(k + 1).$$

## Пример сильной индукции

> **Теорема 4.5**
> Каждое натуральное число $n \ge 2$ можно представить в виде произведения простых чисел.

_Доказательство:_

Обозначим утверждение: $$P(n): \quad n \space \text{представляется в виде произведения простых чисел}.$$

__Базовый случай__

Число 2 является простым. Поэтому оно само является произведением простых чисел, состоящим из одного множителя 2.

Следовательно, $P(2)$ истинно.

__Сильное индукционное предположение__

Пусть для некоторого $k \ge 2$ каждое число $$2, 3, ..., k$$ представляется в виде произведения простых чисел. Докажем утверждение для $k + 1$.

__Индукционный переход__

Рассмотрим число $k + 1$. Возможны два случая.

_Случай 1. Число $k + 1$ простое_

Тогда оно уже представлено как произведение одного простого множителя $k + 1$.

_Случай 2. Число $k + 1$ составное_

Тогда существуют натуральные числа $a$ и $b$, такие что: $$k + 1 = ab,$$ где: $$2 \le a \le k, \quad 2 \le b \le k.$$

По сильному индукционному предположению числа $a$ и $b$ представляются в виде произведений простых чисел. Следовательно, их произведение $ab$, то есть $k + 1$, также представляется в виде произведения простых чисел.

В обоих случаях $P(k + 1)$ истинно. Поэтому по принципе сильной индукции: $$\boxed{\forall n \ge 2 : \quad n \space \text{представляется в виде произведения простых чисел}}$$

$\square$

## Обычная и сильная индукция

| Обычная индукция                      | Сильная индукция                                |
| ------------------------------------- | ----------------------------------------------- |
| Предполагается только \(P(k)\)        | Предполагаются \(P(n_0),\ldots,P(k)\)           |
| Доказывается \(P(k+1)\)               | Доказывается \(P(k+1)\)                         |
| Удобна для рекуррентных формул и сумм | Удобна для разложения объектов на меньшие части |
| Использует один предыдущий случай     | Использует любое количество предыдущих случаев  |

Сильная индукция не является "более истинной" или принципиально более мощной логикой. В стандартной математике обычная и сильная индукция эквивалентны по доказательной силе. Различается удобство применения.

## Типичные ошибки

_Ошибка 1. Проверка нескольких первых значений_

_Ошибка 2. Отсутствие базового случая_

_Ошибка 3. Использование утверждения $P(k + 1)$ при его доказательстве_

_Ошибка 4. Неправильное начало индукции_

_Ошибка 5. Неправильная работа с неравенствами_
